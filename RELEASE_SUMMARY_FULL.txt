1. HIGH-LEVEL DESCRIPTION
=========================

TS-Reasoner v40.0.0 composes the v32-v39 roadmap into a local verifier-first
research OS. It can compile taught domains into operational ontologies, compile
language into typed operation plans, maintain receipt-gated memory, generate
bounded research experiments, audit and repair stale reasoning/project state,
stage confirmation-gated patches, audit the wider TS ecosystem, evaluate model
proposers, and prepare a bounded next-release candidate.

The proof boundary is explicit:

  - generated text is not proof;
  - model confidence is not proof;
  - memory is not proof;
  - repeated experience is not proof;
  - curriculum examples are not proof;
  - user confirmation is not proof;
  - typed verifier support remains proof authority.

4. PRIMARY COMMANDS
===================

Generate the v32-v40 receipt pack:

  python3 scripts/evaluate_v32_v40_research_os.py

Run the v40 mission surface:

  python3 -m ts_reasoner.cli research-os \
    --mission "prepare the next safe TS-Reasoner release candidate" \
    --repo .

Compile a TS-AGL operation plan:

  python3 -m ts_agl.compiler \
    "audit this repo for release readiness and prepare the next safe action"

Run all tests:

  python3 -m unittest discover -q
